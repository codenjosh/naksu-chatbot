\# Naksu AI Chatbot 🤖



A multi-model AI chatbot built with Python and Streamlit, supporting Google Gemini and local Ollama models.



\## Features



\- Google Gemini API integration

\- Local Ollama integration

\- Conversation history

\- Streamlit web interface

\- Dockerized application

\- Deployed using Render

\- Environment variable based API key configuration



\## Technologies



\- Python

\- Streamlit

\- Google Gemini API

\- Ollama

\- Docker

\- Git \& GitHub

\- Render
